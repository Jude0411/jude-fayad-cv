Assignment 3 - Portfolio Website with GitHub API
The website fetches public GitHub repositories using JavaScript fetch() from https://api.github.com/users/Jude0411/repos . No API key is required.
The API section shows loading, errors, repository names, descriptions, languages and stars.
To deploy: upload index.html, styles.css, script.js, and images/ to the existing GitHub repository connected to the Vercel project. Confirm the production URL is live before submission.
The contact form validates input on the client side; it does not send messages to a server.
